# 小売向け店舗マネジメントアプリ 画面遷移図（単店舗版・MVP）

最終更新: 2026-09-07  
基準: 店舗共通、ロール別アクセス、将来store切替に拡張可能。

## 1. 主要導線

### 1.1 売上監視導線（要件優先）
`/auth/login`  
`→` `/`（ダッシュボード）  
`→` `/sales/import`（取り込み監査）  
`→` `/sales/transactions`（明細検証）  
`→` `/sales/transactions/:id`（明細確認）  
`→` `/sales/summary`（集計確認）  

### 1.2 在庫運用導線
`/`  
`→` `/inventory/products`（商品登録）  
`→` `/inventory/list`（在庫確認）  
`→` `/inventory/movements`（補正入力）  
`→` `/inventory/count`（棚卸）

### 1.3 スタッフ運用導線
`/`  
`→` `/staff/schedule`（シフト登録）  
`→` `/staff/attendance`（実績登録/承認）  

### 1.4 経費・帳票導線
`/`  
`→` `/expenses/entries`（経費登録）  
`→` `/reports/pnl`（月次締め）  
`→` `/reports/kpi`（運営KPI）

### 1.5 管理導線
`/`  
`→` `/settings/users`（ロール配布）  
`→` `/settings/audit-logs`（監査）  

## 2. 画面遷移ルール（確定）

- 監査アクションから戻る対象
  - `/sales/import` の再処理完了 → `/sales/transactions`
  - `/inventory/count` 差分確定申請 → `/inventory/list`
  - `/reports/pnl` 月次ロック実行 → `/settings/audit-logs`
- グローバル共通のエラーフロー
  - 権限不足: 画面内トースト + `403` 表示
  - 月次ロック済み変更: 確認モーダル（解除不可）
  - 同期待ち/失敗: 画面上部にステータスバナー

3. シフト/勤怠（運営実装）  
4. 月次処理（損益・KPI）
