# 小売向け店舗マネジメントアプリ 画面仕様（確定版・v2）

最終更新: 2026-09-07  
対象: 一店舗運用を起点に、将来の複数店舗管理へ拡張可能な画面仕様を確定する

## 1. 画面仕様のゴール

- 単店舗向け運用をまず成立させる  
- POP（POS）連携を最優先で実装可能にする  
- 後から複数店舗に拡張できるよう、画面状態・権限・集計を `store_id` 前提で設計する  
- 「必要」要件を最優先し、現場で負担になりやすい機能は意図的に後回しにする  

## 2. 採用する前提（確定）

- 店舗共通マスタ・比較ロジック（将来必須）は初期から保持する
  - 例: 決済種別、税率、商品カテゴリ、経費科目、取引取消ルール
- 店舗比較機能・店舗横断在庫可視化は**将来対応前提でモデル化**し、単店舗時は表示制御
- 必要性が薄い／運用負荷が高いものは初期対象外
  - 高度な販促モジュール（キャンペーン最適化など）
  - 高度なAIレコメンド
  - 顧客LTV分析（顧客基盤がまだ無い前提）

## 3. 画面構成（確定）

### 3.1 共通レイアウト

- 左サイドバー + 上部バー（店内業務中心の固定導線）
- 上部バー要素
  - 日付（営業日）選択
  - 店舗名（単店舗時は固定表示）
  - 監査ログ・ヘルプ
- 権限別UI制御
  - OWNER: 全画面＋ユーザー管理
  - MANAGER: 業務画面＋売上訂正申請承認
  - STAFF: 入力寄り画面（打刻・在庫補正申請等）
  - VIEWER: 閲覧のみ

## 4. 必須画面（MVP.1）

### 4.1 ダッシュボード `/`
**目的**: 今日の運営状態を1画面で把握  
**要素（必須）**
- 本日売上 / 粗利 / 注文件数
- 在庫アラート件数（欠品・期限間近）
- POS未同期件数（取り込み失敗含む）
- 今日のシフト充足率
- 月次重要アラート（締めロック/承認待ち）

### 4.2 POS取り込み監査 `/sales/import`
**目的**: POP連携の運用信頼性を確保  
**要素（必須）**
- 取り込みイベント一覧（時刻, terminal_id, transaction_id, status, retry_count, エラー）
- 再処理ボタン
- 重複/再送ログの追跡
- 手動補正申請導線
- 再送失敗時の担当者通知

### 4.3 取引一覧 `/sales/transactions`
**目的**: 取引明細の確認と修正受付  
**要素（必須）**
- 取引ID / 時刻 / 金額 / 税額 / 支払方法 / 返品フラグ / 確定状態
- 伝票詳細（明細行）
- 訂正申請（直接編集なし）
- フィルタ（日時レンジ、端末、支払、返品）

### 4.4 売上集計 `/sales/summary`
- 日次・週次・月次の集計
- CSVエクスポート
- 税・値引・返品・粗利を表示

### 4.5 商品マスタ `/inventory/products`
- SKU, 品名, カテゴリ, 原価, 売価, 税率, 最低在庫, 保管場所
- 大量更新（CSV）
- 非アクティブ化

### 4.6 在庫一覧 `/inventory/list`
- 商品名 / 現在庫 / 予約在庫 / 利用可能在庫 / アラート差分
- 不足/期限警告の色表示
- 在庫補正申請（手入力）

### 4.7 入出庫 `/inventory/movements`
- 種別（入庫/出庫/返品補正/棚卸補正）
- 売上連動在庫はPOS連携イベントで自動反映
- 手入力は監査ログに必須記録

### 4.8 棚卸 `/inventory/count`
- 棚卸開始 → 実数入力 → 差分確定 → 承認の3ステップ
- 差分は店長以上の承認後に反映

### 4.9 スタッフシフト `/staff/schedule`
- 月次カレンダー
- シフト登録・欠勤入力・交替
- 重複シフト警告

### 4.10 勤務実績 `/staff/attendance`
- 打刻/実働時間/残業/承認
- 集計CSV

### 4.11 経費入力 `/expenses/entries`
- 日付, 科目, 金額, 支払先, 備考, 画像メモ（任意）
- 月次PLへ反映
- ステータス（申請, 承認, 差戻し）

### 4.12 月次損益 `/reports/pnl`
- 売上 / 原価 / 粗利 / 人件費 / 固定費 / 営業利益
- 締めロック（日次・月次）と監査トレイル
- 前月比較

### 4.13 KPI `/reports/kpi`
- 粗利率・在庫回転率・欠品率・返品率・人件費率
- 目標値と乖離を表示（初期は管理者のみ設定可）

### 4.14 ユーザー権限 `/settings/users`
- ユーザー招待/無効化
- 店舗ロール割当
- 画面別権限制御

### 4.15 監査ログ `/settings/audit-logs`
- 対象, 操作種別, 変更前後, 操作時刻
- 日付・ユーザー・画面単位で検索

## 5. 将来画面（開発順次入）

- 仕入 `procurement/*`（発注・仕入履歴）
- 店舗比較 `reports/store-comparison`
- 店舗横断在庫一覧 `inventory/stock-cross`  
- 支払先別採算レポート

## 6. 画面遷移（確定）

`/sales/import` で再処理登録 → `/sales/transactions` で検証  
`/inventory/list` から `+` で `/inventory/movements`  
`/inventory/list` から `棚卸開始` で `/inventory/count`  
`/reports/pnl` から `月次ロック` → `settings/audit-logs` へ

## 7. 除外/延期（初期非対象）

現時点で追加しない（MVP外）
- 顧客CRM連携（CRM ID/メンバーシップ機能）
- 高度な棚割り最適化
- 複数店舗同時入力UI（複数窓・一括更新）

これらは将来フェーズで要件再確認後に追加する。

## 8. マイルストーン（画面）

1. 売上同期監査 + 取引一覧  
2. 商品マスタ + 在庫一覧 + 入出庫  
3. シフト + 勤務実績  
4. 月次損益 + KPI  
5. 経費入力 + 仕入画面
6. 店舗比較画面（store_id対応）
