# 小売向け店舗マネジメントアプリ 画面仕様 v1（単店舗先行・将来マルチ店舗対応）

最終更新: 2026-09-06  
対象: 店舗運営に必要な業務画面の確定版（実装設計用）

## 1. 画面方針（共通）
- ナビゲーション: 左サイドナビ + 上部固定バー
- 上部バー左: 現在表示中店舗（初期は固定: 単店舗、将来は store 切替）
- 右下: 主要画面の新規追加は共通「+」ボタン
- 全画面共通:  
  - 日付・担当者・カテゴリのフィルタ（対象画面のみ）
  - 保存/取消し/監査ログ参照
  - ロール権限に応じてボタン表示を制御

## 2. ロール
- オーナー
  - 全画面編集可、監査ログ閲覧可、月次ロック解除可
- 店長
  - 売上/在庫/スタッフ/経費の編集可、監査ログ閲覧可、月次ロック解除不可
- スタッフ
  - シフト入力・勤務実績入力・在庫/経費の閲覧
  - 売上訂正は不可
- 閲覧専用
  - 表示のみ

## 3. 画面一覧（確定）

### 3.1 ダッシュボード `/`
- 本日サマリ
  - 本日売上、本日粗利、在庫不足数、未確定修正アラート、POS未同期件数、今日の予定人員
- グラフ
  - 売上推移（7日/30日）
- アラート
  - 在庫不足数（在庫一覧へのリンク）
  - 未同期取引（売上取込監査へのリンク）

### 3.2 売上
#### 3.2.1 売上取込監査 `/sales/import`
- 表示: `timestamp, terminal_id, transaction_id, status, retry_count, error_message`
- 機能:
  - 再取り込み
  - 再送失敗理由の注記
  - 手動修正申請
- 権限: 店長以上

#### 3.2.2 取引一覧 `/sales/transactions`
- 表示: 取引ID、時刻、合計、税額、支払方法、返品フラグ、確定状態
- 機能:
  - 詳細表示
  - 返品/訂正申請
- 制約: 直接編集不可。訂正は申請フロー
- 権限: 店長以上

#### 3.2.3 売上集計 `/sales/summary`
- 集計軸: 日次／週次／月次
- フィルタ: 日付レンジ、カテゴリ、決済、スタッフ
- 出力: CSV
- 指標: 売上、税、値引、返品、粗利
- 権限: 全ロール閲覧可、再集計実行は店長以上

### 3.3 在庫
#### 3.3.1 商品マスタ `/inventory/products`
- 入力: SKU, 品名, カテゴリ, 原価, 売価, 税率, 最低在庫, 保管場所
- 機能: 新規/更新/非アクティブ化/一括取込
- 権限: オーナー・店長

#### 3.3.2 在庫一覧 `/inventory/list`
- 表示: 商品, 現在庫, 保留在庫, 利用可能在庫, 最小在庫までの差, 最終更新
- ハイライト:
  - 不足: 赤
  - 期限間近: 黄
- 権限: 全ロール閲覧可、在庫補正編集は店長以上

#### 3.3.3 入出庫 `/inventory/movements`
- 入力: 種別(入庫/出庫/返品補正/棚卸補正), 商品, 数量, 理由, 担当, 日時
- 売上連動在庫は API 自動反映
- 手入力は監査ログ保存
- 権限: オーナー・店長編集

#### 3.3.4 棚卸 `/inventory/count`
- フロー: 棚卸開始 → 実在庫入力 → 差分確認 → 承認確定
- 表示: 理論在庫、実在庫、差分、理由、承認者
- 権限: 差分確定は店長以上

### 3.4 仕入
#### 3.4.1 仕入先マスタ `/procurement/suppliers`
- 入力: 仕入先名, 連絡先, リードタイム, 備考, 停止フラグ
- 権限: オーナー・店長

#### 3.4.2 仕入履歴 `/procurement/purchases`
- 表示: 発注日, 仕入日, 合計, 入庫率, 未入庫
- 権限: 店長以上

### 3.5 スタッフ
#### 3.5.1 シフト `/staff/schedule`
- 月次カレンダー + 営業時間
- 操作: 登録/編集/移動/欠勤入力
- バリデーション: 重複勤務NG
- 権限: 店長編集、スタッフ本人は本人分のみ

#### 3.5.2 勤務実績 `/staff/attendance`
- 表示: 打刻, 実働時間, 残業, 承認状態
- 権限: 店長承認

#### 3.5.3 人件費 `/staff/payroll`
- 指標: 日別・人別・時給別の人件費、人件費率
- 権限: 店長以上

### 3.6 経費
#### 3.6.1 経費入力 `/expenses/entries`
- 入力: 日付, 科目, 金額, 支払先, 備考, 領収書有無
- 月次PLへ即時反映
- 権限: 全ロール入力可、承認は店長以上

#### 3.6.2 経費カテゴリ `/expenses/categories`
- 属性: 固定費/変動費, 会計科目
- 権限: オーナーのみ編集

### 3.7 レポート
#### 3.7.1 月次損益 `/reports/pnl`
- 指標: 売上/原価/粗利/人件費/固定費/営業利益
- 機能: 月次締めロック、CSV出力
- 権限: 店長以上

#### 3.7.2 KPI `/reports/kpi`
- 指標: 粗利率、在庫回転率、欠品率、返品率、人件費率
- 比較: 前月比、先月同日比
- 権限: 全ロール閲覧可、設定は店長以上

#### 3.7.3 店舗比較（将来）`/reports/store-comparison`
- 現時点: 表示のみ。将来 store_id 前提で有効化

### 3.8 設定
#### 3.8.1 ユーザー権限 `/settings/users`
- ロール管理、画面別権限制御の編集
- 権限: オーナー

#### 3.8.2 監査ログ `/settings/audit-logs`
- 表示: ユーザー, 対象, 操作, 変更前/変更後, 時刻
- フィルタ: 日付・ユーザー・種別
- 権限: 店長以上

### 3.9 認証
- ログイン: メール + パスワード
- 2FA: メールOTP（初期）
- ログアウト/セッションタイムアウト

## 4. 開発順（MVP）
1. 売上同期監査 + 取引一覧
2. 商品マスタ/在庫一覧/入出庫
3. シフト + 勤務実績
4. 月次損益 + KPI
5. 仕入・経費
6. 店舗比較画面（store_id構造先行）

## 5. 店舗共通/拡張要件（将来）
- 画面は `store_id` のない単一表示から開始
- 共通化対象: カテゴリ、税率、決済種別、科目
- 将来の店舗比較・店舗横断在庫可視化に対応したテーブル粒度を維持
- 店舗比較画面は権限付きで段階有効化
